# YagsCustom

focused on enterprise applications, distributed systems, cloud platforms,
and AI-enabled software.

### Java & Spring
Java, Spring Boot, REST APIs, microservices, security, resilience,
testing, and observability.

### AI & Agentic Systems
AI agents, LLM integration, tool-based workflows, structured outputs,
and enterprise AI integration.

### Data & Persistence
PostgreSQL, Spring Data JPA, transactional systems, caching,
database migrations, and data architecture.

### Event-Driven Architecture
Kafka, asynchronous messaging, event processing, idempotency,
retries, and distributed-system patterns.

### AWS & Cloud
AWS application architecture, containers, serverless integration,
infrastructure automation, security, and observability.
